# Voice-over panduan VR

Letakkan rekaman voice over panduan VR di folder ini (MP3), dengan nama file
persis seperti di `docs/VR-GUIDE-VOICEOVER.md` (mis. `01-intro.mp3`,
`controller-03-select.mp3`, `hand-03-select.mp3`). File yang belum ada
dilewati tanpa suara — panduan tetap berjalan dengan teks.
